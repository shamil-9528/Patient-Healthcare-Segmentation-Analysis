# 🏥 Patient Healthcare and Segmentation Analysis Dashboard

## 📊 Project Overview
This project analyzes healthcare patient data to identify patterns in demographics, medical conditions, insurance types, billing behavior, and healthcare utilization.  
The dashboard helps segment patients and provides insights that support better healthcare decision-making.

---


## 📌 Key Insights
- 👥 **Total Patients:** 2000  
- 💰 **Average Billing Amount:** 4000  
- ⚖️ **Average BMI:** 30.73  
- 📈 Highest patient group: **Age 30–50**  
- 🏥 Patients with multiple chronic conditions have **higher visits and billing**  
- 💳 **Medicare insurance** shows the highest average billing

## 📂 Dataset Columns

| Column | Description |
|------|-------------|
| Patient ID | Unique identifier for each patient |
| Age Group | Patient age category |
| Gender | Male / Female |
| Primary Condition | Main diagnosed health condition |
| BMI Category | Body Mass Index category |
| Insurance Type | Type of health insurance |
| Annual Visits | Number of hospital visits per year |
| Avg Billing Amount | Average healthcare billing |
| Num Chronic Conditions | Number of chronic diseases |
| State | Patient location |

## 🎯 Project Objectives

- Understand patient demographics and health conditions  
- Analyze billing patterns across insurance types  
- Identify healthcare utilization trends  
- Segment patients based on medical and demographic attributes  

---

## ✅ Conclusion
The analysis shows that healthcare costs and visit frequency increase with age and the number of chronic conditions. Insurance type also significantly influences billing amounts, providing useful insights for healthcare planning and resource allocation.
